## Visual Style Guidelines

### Color Scheme
- **Primary:** Modern tech blues and greens (matching the dashboard)
- **Accent:** White text on dark overlays for readability
- **Background:** Keep dashboard/app colors authentic

### Typography
- **Main titles:** Bold, modern sans-serif (e.g., Montserrat Bold, Roboto Bold)
- **Subtitles:** Regular weight, same font family
- **Size:** Large enough to read on mobile devices

### Transitions
- **Between sections:** Smooth fades or subtle slides (0.5-1 second)
- **Within sections:** Quick cuts for energy (0.3 seconds)
- **Avoid:** Overly flashy transitions that distract from content

### Pacing
- **Overall:** Dynamic but not rushed
- **Feature sections:** 15 seconds each to allow viewers to absorb information
- **Text overlays:** Display for 3-5 seconds minimum (enough time to read twice)

## Animation Effects

### Text Animations
- **Entry:** Fade in + slight slide up
- **Exit:** Fade out
- **Emphasis:** Subtle scale pulse for key benefits

### Screen Recording Enhancements
- **Cursor highlights:** Add subtle glow or circle around cursor clicks
- **UI element highlights:** Add subtle borders or arrows pointing to key features
- **Zoom effects:** Zoom in slightly on important UI elements (2-3 seconds)

### Motion Graphics
- **Icons:** Animate checkmarks, arrows, or icons that appear with text
- **Data visualization:** If showing statistics, animate numbers counting up
- **Map elements:** Smooth drone movement paths, pulsing location markers

## Audio Guidelines

### Background Music
- **Style:** Corporate/tech, upbeat but not overwhelming
- **Tempo:** 120-130 BPM
- **Volume:** Background level, never overpowering
- **Fade:** Fade in at start, fade out at end

### Sound Effects (Optional)
- **UI interactions:** Subtle click sounds for button presses
- **Transitions:** Soft whoosh for section changes
- **Notifications:** Gentle ping for alert demonstrations
- **Keep minimal:** Don't overuse

### Voiceover (Optional)
- If adding voiceover, use professional, friendly tone
- Script should match text overlays
- Clear pronunciation, moderate pace
